# TestImageGenerator 使用说明

## ✅ 当前逻辑（下载一次即可）

### 核心特性
- ✅ **首次启动**：自动下载/生成所有菜品图片
- ✅ **后续启动**：检测到图片后**直接跳过**，不会重复下载
- ✅ **用户上传**：检测到任意图片后即停止自动下载

### 启动流程

```
首次启动（无图片）
┌─────────────────────────────────┐
│ 检测到菜品图片目录为空            │
│ 开始初始化图片...                │
│ ⬇️ 正在下载真实图片...           │
│ ✅ 下载成功 19 张                │
│ 💡 下次启动将跳过下载             │
└─────────────────────────────────┘

后续启动（有图片）
┌─────────────────────────────────┐
│ 检测到 19 张菜品图片              │
│ ✅ 用户已上传或已生成，跳过自动下载 │
└─────────────────────────────────┘
```

## ⚙️ 配置说明

### 当前配置（application.yml）

```yaml
reggie:
  image:
    # 是否在启动时下载真实网络图片
    # true  = 仅首次启动时下载（默认）
    # false = 完全禁用下载功能
    download-real-images: true

    # 网络图片下载超时时间（毫秒）
    download-timeout: 10000
```

## 🛑 禁用自动下载功能

### 方法一：修改配置（推荐）

在 `application.yml` 中关闭：

```yaml
reggie:
  image:
    download-real-images: false
```

**效果**：
- 启动时不会下载网络图片
- 也不会生成本地图片
- 完全静默，无日志输出

---

### 方法二：删除或注释 TestImageGenerator 类

删除整个类文件：
```bash
# 备份
mv src/main/java/com/reggie/util/TestImageGenerator.java src/main/java/com/reggie/util/TestImageGenerator.java.bak

# 或注释掉 @Component 注解
```

**效果**：
- 完全禁用图片自动下载/生成
- 需要手动上传所有图片

---

### 方法三：使用 Spring Profile

给类添加环境注解，仅在开发环境启用：

```java
@Profile("dev")  // 仅在 dev 环境启用
@Component
public class TestImageGenerator implements CommandLineRunner {
    ...
}
```

**效果**：
- 开发环境（dev）：自动下载图片
- 生产环境（prod）：禁用自动下载

## 📤 用户上传图片（后续方案）

### 图片存储位置

```
uploads/
└── images/
    └── dishes/
        ├── hongshaorou.jpg      ← 用户上传的图片
        ├── gongbaojiding.jpg    ← 用户上传的图片
        └── ...
```

### 图片命名规则

```
{菜品英文名}.jpg

示例：
- 红烧肉   → hongshaorou.jpg
- 宫保鸡丁 → gongbaojiding.jpg
- 鱼香肉丝 → yuxiangrous.jpg
```

### 上传流程

1. 管理员在后台上传菜品图片
2. 图片保存到 `uploads/images/dishes/`
3. 系统自动检测到图片存在
4. **停止自动下载**，使用用户上传的图片

### 检测逻辑

```java
// TestImageGenerator 核心逻辑
File dir = new File(dishesDir);

// 只要检测到任意图片文件，立即跳过
if (dir.exists() && dir.isDirectory()) {
    File[] files = dir.listFiles();
    if (files != null && files.length > 0) {
        long imageCount = java.util.Arrays.stream(files)
            .filter(f -> f.isFile() && (f.getName().endsWith(".jpg") || f.getName().endsWith(".png")))
            .count();
        if (imageCount > 0) {
            log.info("✅ 检测到 {} 张菜品图片，跳过自动下载", imageCount);
            return;  // 跳过下载
        }
    }
}
```

## 🔧 自定义菜品图片

### 添加新菜品

#### 步骤1：准备图片
```
准备图片文件：新菜品.jpg
建议尺寸：400x300 像素
格式：JPG/PNG
大小：< 500 KB
```

#### 步骤2：重命名并放入目录
```bash
# 按英文名命名
mv 新菜品.jpg hongshaorou.jpg

# 放入图片目录
cp hongshaorou.jpg uploads/images/dishes/
```

#### 步骤3：重启应用
```bash
# 系统会检测到图片已存在，不会自动下载
./mvnw spring-boot:run
```

```bash
# 1. 准备新图片

mv 准备新图片.jpg uploads/images/dishes/hongshaorou.jpg

# 3. 重启应用
# 系统会检测到图片已存在，直接使用
```

## ⚠️ 注意事项

### 图片优先级
1. **用户上传图片**（`uploads/images/dishes/`）→ 优先级最高
2. **自动下载图片**（首次启动）→ 仅执行一次
3. **本地生成图片**（降级方案）→ 最后 resort

### 启动行为
- ✅ **检测到任意图片** → 跳过所有下载/生成
- ✅ **检测到假图片**（< 1KB） → 自动删除后重新生成
- ✅ **空目录** → 执行初始化下载/生成

### 生产环境建议
1. 设置 `download-real-images: false`
2. 提前准备所有菜品图片
3. 使用 CDN 或对象存储（OSS/S3）
4. 配置图片压缩和 WebP 格式
