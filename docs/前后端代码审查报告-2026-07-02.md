### 1. ❌ **缺少跨域配置（CRITICAL）**

**问题**：前后端分离架构，但没有配置跨域支持

**影响**：
- 开发环境：前端 localhost:8080，后端 localhost:8080，同域暂时没问题
- 生产环境：如果前后端分离部署，会报 CORS 错误

**位置**：`src/main/java/com/reggie/config/WebMvcConfig.java`

**修复**：添加跨域配置

```java
@Configuration
public class WebMvcConfig extends WebMvcConfigurationSupport {

    // ... 现有代码 ...

    /**
     * 跨域配置
     */
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
            .allowedOriginPatterns("*")
            .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
            .allowedHeaders("*")
            .allowCredentials(true)
            .maxAge(3600);
    }
}
```

### 2. ❌ **CSRF 防护可能阻止合法请求（HIGH）**

**问题**：CSRFFilter 在非测试环境启用，对 POST/PUT/DELETE 请求验证 Token

**影响**：
- 前端登录接口 `/employee/login` 需要 CSRF Token，但登录前无法获取
- 其他 POST/PUT/DELETE 请求需要携带 Token

**位置**：
- `src/main/java/com/reggie/filter/CsrfFilter.java`
- `src/main/resources/backend/page/login/login.html`

**分析**：
- CSRFFilter 排除路径包含 `/employee/login` ✓
- 但其他需要认证的接口（如 `/employee/page`）需要 CSRF Token

**修复方案**：
1. **确保前端登录页在第一次 GET 请求时获取 CSRF Token**
2. **后续请求通过 Header 或 Cookie 携带 Token**

**检查点**：
- 后端 `/backend/**` 在 CSRF 排除列表中 ✓
- 但 `/backend/index.html` 中的接口调用需要验证 Token

## 🔧 立即修复（P0）

### 1. 添加跨域配置

创建 `src/main/java/com/reggie/config/CorsConfig.java`：

```java
package com.reggie.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;
import org.springframework.web.filter.CorsFilter;

import java.util.List;

@Configuration
public class CorsConfig {

    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOriginPatterns(List.of("*"));
        config.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE", "OPTIONS"));
        config.setAllowedHeaders(List.of("*"));
        config.setAllowCredentials(true);
        config.setMaxAge(3600L);

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);

        return new CorsFilter(source);
    }
}
```

### 2. 验证 CSRF Token 传递

**检查点**：
1. 登录页第一次加载时，是否能获取到 Cookie 中的 CSRF Token
2. 后续请求是否自动携带 Token

**验证方法**：
- 打开浏览器开发者工具 → Application → Cookies
- 查看是否存在 `XSRF-TOKEN` Cookie
- 检查请求 Header 中是否有 `X-CSRF-TOKEN`

**如果缺少 CSRF Token**：
- 访问 `/backend/page/login/login.html` 时，应该触发一次 GET 请求
- CsrfFilter 在 GET 请求时生成 Token 并写入 Cookie
- 前端需要从 Cookie 读取 Token 并写入请求 Header
