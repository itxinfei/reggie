二、跨端优先修复清单（Top 10）

按「严重度 × 影响面 × 修复成本」排序。P0 = 必须尽快修复（可访问性硬性违规 / 性能硬伤 / 规范逻辑矛盾），P1 = 应修复（可维护性 / 隐性 bug），P2 = 建议优化。

P0 生产仍伺服 Vue 开发版（dev build）

backend/index.html:170 · front/page/tracking.html:170 · rider 各页 三端均引入 plugins/vue/vue.js（含完整警告、未压缩），而非 vue.min.js。影响：首屏 JS 体积与 TBT 明显劣化，直接拖累 CWV。建议：切换到 vue.min.js，零逻辑风险、收益最大。

P0 骑手端 8 个页面锁定缩放（WCAG 1.4.4 硬性违规）

rider/*.html:5（全部 8 页） viewport 含 maximum-scale=1.0, user-scalable=no。影响：户外/低视力/老年骑手无法放大订单地址、取餐码等关键信息。建议：移除这两项，保留 viewport-fit=cover；用 rem/clamp 响应式字号替代禁缩放。

P0 骑手端「假按钮」键盘/读屏完全不可达

rider/*（全代码零 role/tabindex/aria） 退出、忘记密码、获取验证码、任务卡、消息行、异常类型 chips、转单项均为 <div>/<span> @click；且所用 Vant 构建不做焦点陷阱/Esc。影响：键盘、TalkBack/VoiceOver 用户无法退出登录、无法打开订单详情、无法读消息、无法选异常类型。建议：改为 <button>/<a> 或补 role="button" tabindex="0"+键盘处理，并加全局 :focus-visible 焦点样式。

P0 骑手端对比度违规（白字压金渐变 1.62:1、橙字 2.13:1）

rider.css:227/364 · income.html:84 · evaluation.html:15 选中 Tab 与登录辅助链接用 --color-primary-dark(#ff9a00) 作文字仅 2.13:1；收入/评价摘要条白字压金橙渐变仅 1.62:1（连大字号 3:1 都不达标）。建议：文字改 --color-primary-text-strong(#955f00,5.22:1) / --color-primary-text(#4a3500)，与同端正确的「深字配金底」主按钮范式一致。
