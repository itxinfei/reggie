## 二、修复详情

### 2.1 购物车原子操作

**修复前**：先 `getOne` 查数量，再 `update` 减 1，两步非原子，高并发下可能负数。

**修复后**：
```java
// 新增原子方法
public int subQuantityAtomically(Long itemId) {
    LambdaUpdateWrapper<ShoppingCart> uw = new LambdaUpdateWrapper<>();
    uw.eq(ShoppingCart::getId, itemId)
      .gt(ShoppingCart::getNumber, 1)
      .setSql("number = number - 1");
    return this.update(uw) ? 1 : 0;
}
```
Controller 层改用原子方法，避免先查后改的竞态。

### 2.2 取消/拒单回退库存

### 2.3 幂等令牌改用 UUID

**修复前**：`userId_timestamp_random6`（`Math.random()` 非线程安全）

**修复后**：`userId_timestamp_uuid8`（`UUID.randomUUID()` 全局唯一）

### 2.4 初始密码安全

**修复前**：`return R.success("新增员工成功，初始密码：" + initialPassword);`

**修复后**：返回脱敏消息，密码通过短信/邮件发送。

### 2.5 Session Fixation 防护

**修复后**：登录成功后调用 `request.changeSessionId()`，防止攻击者利用预知 Session ID 进行劫持。

### 2.6 XSS 防护

**修复后**：评价内容入库前调用 `StringEscapeUtils.escapeHtml4()` 转义 HTML 特殊字符。

### 2.7 异步线程 ThreadLocal 传递

**修复后**：`AsyncConfig` 添加 `TaskDecorator`，在任务提交到线程池前捕获 `BaseContext` 中的 userId 和 tenantId，在线程中恢复，执行完后清理。

## 三、数据库索引建议

详见 `docs/数据库唯一索引建议.sql`，主要建议：

1. **购物车**：`(user_id, dish_id)` / `(user_id, setmeal_id)` 唯一索引
2. **订单号**：`number` 唯一索引
3. **评价**：`(user_id, dish_id, order_id)` 唯一索引
4. **订单状态**：`status` 索引
5. **订单明细**：`order_id` 索引
6. **用户手机号**：`phone` 索引
7. **员工用户名**：`username` 索引
8. **订单时间**：`order_time` 索引
