## 二、架构层问题（最高优先级）

### 1. iframe 嵌套架构（严重）
- 每个页面都是独立的 HTML + Vue 实例，加载时产生额外的 HTTP 请求和内存开销
- iframe 间无法直接通信，全局状态（用户信息、筛选条件）无法共享
- 浏览器前进/后退按钮失效
- 无法做全局 loading、全局错误处理
- **建议：** 短期提取公共 JS/CSS；中期迁移到 Vue CLI/Vite 工程化项目；替换 iframe 为 Vue Router + 路由视图

### 2. 无前端路由
- 所有页面跳转使用 `window.location.href`，没有前端路由
- 无法做路由守卫、页面切换没有过渡动画
- **建议：** 引入 Vue Router，定义路由表，配置路由守卫

### 3. 无状态管理
- 每个页面独立维护 data，没有全局状态管理
- 用户信息在多个页面重复读取 localStorage
- 购物车数据在不同页面间不同步
- **建议：** 引入 Pinia，统一管理用户、购物车、筛选条件等全局状态

## 六、安全审查

### 高危
| # | 问题 | 建议 |
|---|------|------|
| 1 | v-html XSS（AI 助手） | 引入 DOMPurify |
| 2 | API 响应未过滤直接渲染 | 后端 XSS 过滤或 v-text |
| 3 | 前端权限判断可绕过 | 权限控制移到后端 |
| 4 | 前端价格计算可被篡改 | 后端重新计算价格 |

### 中危
- 手机号/身份证号明文展示 → 脱敏
- 无 CSRF Token → request.js 统一添加
- 退款操作无二次验证 → 增加操作密码

## 七、性能问题

| # | 问题 | 建议 |

## 八、代码质量

### CSS 重复（严重）
统计卡片样式在 10+ 个文件中完全复制粘贴，每个文件约 70-80 行。提取到 common.css。

### 错误处理不统一
- String(res.code) === '1' 与 res.code === 1 混用
- catch(() => {}) 吞掉异常
- 重复的 this.$message.error

### 魔法数字
- 订单状态 1/2/3/4/5 硬编码
- pageSize: 1000 硬编码
- 金额 /100 转换散落各处

2. 🔴 架构：iframe 架构难以维护和扩展
3. 🟠 数据：前端统计逻辑错误且性能差
