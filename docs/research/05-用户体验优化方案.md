# 用户体验优化方案

> 版本：v2.0 | 日期：2025-07-08

## 一、当前体验问题诊断

### 1.1 首页（仪表盘）

**当前问题**：
```
┌──────────────────────────────────────────────┐
│  [概览] [近7日趋势]  [订单状态分布]             │  ← 三个tab挤在一起
│                                              │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐           │
│  │订单数│ │销售额│ │菜品数│ │...   │           │  ← 卡片信息密度低
│  └─────┘ └─────┘ └─────┘ └─────┘           │
│                                              │
│  [一条简单的折线图...]                        │  ← 信息太少，无法支撑决策
│                                              │
│  [三个饼图并排...]                             │
└──────────────────────────────────────────────┘
```

**问题总结**：
- ❌ 无实时数据刷新（页面需要手动刷新）
- ❌ 卡片只显示数字，无趋势箭头（↑/↓）
- ❌ 缺少核心经营指标（客单价、翻台率、毛利率）
- ❌ 图表过于简单，无交互（无法下钻）
- ❌ 无预警/异常提示区域
- ❌ 无同比/环比对比

### 1.2 侧边栏导航

**当前问题**：
- ✅ 已解决（上一轮优化已收紧宽度至200px）

### 1.3 列表页

**当前问题**：
- ❌ 搜索条件简陋（通常只有1-2个输入框）
- ❌ 列表无批量操作（批量删除/上下架/导出）
- ❌ 表格列过多时无横向滚动提示
- ❌ 数据刷新需重新查询
- ❌ 无列排序功能
- ❌ 无列显隐控制

### 1.4 表单页

**当前问题**：
- ❌ 长表单无分步/分组
- ❌ 图片上传无裁剪/压缩
- ❌ 下拉选项过多时无搜索
- ❌ 无草稿保存
- ❌ 提交后无明确反馈（成功/失败信息一闪而过）
- ❌ 无表单校验实时提示

### 1.5 用户端（前台）

**当前问题**：
- ❌ 登录页无法看到验证码（已修复→打印日志）
- ❌ 菜品列表无骨架屏（白屏等待）
- ❌ 无搜索功能
- ❌ 无历史订单/常点菜品快捷入口
- ❌ 无评价/收藏功能
- ❌ 移动端体验不佳
