## 一、ai-assistant.html 专项审查

### ✅ 已做的好的设计

| 维度 | 评价 |
|------|------|
| XSS 防护 | 使用 `safeFormatContent` 白名单渲染，不直接 v-html，杜绝注入 |
| 对话管理 | 支持多对话、localStorage 持久化、后端同步合并 |
| 场景切换 | 点餐推荐/菜品描述/营销文案 三场景，各有独立快捷提示 |
| 用户画像 | 基于历史偏好标签，支持本地缓存 + 后端异步获取 |
| 语音输入 | SpeechRecognition 集成，含错误处理和权限提示 |
| 流式消息 | 支持 streaming 光标动画，与 loading 指示器互斥 |
| 反馈机制 | 👍/👎 反馈按钮，后端静默记录 |
| 错误重试 | 失败消息可点击重新生成 |
| ESC 键 | 支持 ESC 关闭侧边栏 |
| 请求竞态 | `currentRequestId` 递增防旧请求覆盖新结果 |

### 🔴 P0 - 必须修复

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **无网络状态检测** | 高 | 用户断网时点击发送无任何提示，消息卡在 loading 状态。需监听 `navigator.onLine` + `online/offline` 事件 |
| 2 | **无消息复制功能** | 高 | 助手回复长文本无法复制，用户体验差。需在每条 assistant 消息气泡旁加复制按钮 |
| 3 | **输入框不支持多行** | 高 | 用户输入长文本时只能看到一行，无法编辑。需支持 `textarea` 自动伸缩或点击展开 |
| 4 | **侧边栏无滑动手势** | 中 | 仅支持点击汉堡按钮打开，无左边缘滑动唤出、右滑关闭手势（移动端标配） |
| 5 | **无骨架屏/加载态** | 中 | 页面初始加载无骨架屏，白屏体验差。需为对话列表区域添加骨架屏 |
| 6 | **无暗色模式** | 中 | 所有颜色硬编码（#FF6B35、#FFF0E6），不支持暗色模式。需改为 CSS 变量 |

### 🟡 P1 - 建议修复

| # | 问题 | 说明 |
|---|------|------|
| 7 | **用户消息无法复制** | 用户发出的消息也没有复制按钮 |
| 8 | **无消息长按菜单** | 移动端长按消息无操作菜单（复制/删除/举报） |
| 9 | **无输入框历史记录** | 不支持 ↑↓ 键切换历史输入内容 |
| 10 | **头像样式单一** | 用户头像永远是 👤，可读取真实头像 |
| 11 | **菜品卡片无骨架** | 加载推荐菜品时无占位图，卡片突然出现体验差 |
| 12 | **无自动滚动优化** | 用户在浏览历史消息时新消息到来会强制滚动到底部，应检测是否在底部 |

## 二、全局设计问题

### 🔴 P0 - 支付方式硬编码

**文件**：`add-order.html`（第 148-155 行）

```html
<!-- 支付方式 — 货到付款 -->
<div class="pay-method">
    <div class="title">支付方式</div>
    <div class="pay-options">
        <div class="pay-option pay-option-cod active">
            <span class="pay-icon pay-cod-icon">货</span>
            <span class="pay-text">货到付款</span>
            <i class="pay-check">✓</i>
        </div>
    </div>
</div>
```

**问题**：仅支持"货到付款"一种支付方式，无微信支付/支付宝选项。如果后端已支持在线支付，前端需要同步添加。

### 🔴 P0 - my-evaluations.html 语法错误

**文件**：`my-evaluations.html` 第 252 行附近

Vue methods 中 `deleteEvaluation` 方法的 `async` 函数体缺少闭合大括号，导致 `getImageList`、`getImageUrl` 等方法被嵌套在 `deleteEvaluation` 内部，这些方法无法被外部正常调用。

### 🟡 P1 - lang 属性不一致

| 文件 | 当前 lang | 应为 |
|------|-----------|------|
| `order.html` | `en` | `zh-CN` |
| `add-order.html` | `en` | `zh-CN` |
| `address.html` | `en` | `zh-CN` |
| `tracking.html` | `en` | `zh-CN` |
| `frequent-orders.html` | `en` | `zh-CN` |
| `user.html` | `en` | `zh-CN` |

**影响**：SEO 和屏幕阅读器无法正确识别中文内容，无障碍访问不达标。

### 🟡 P1 - 外部 CDN 依赖风险

**文件**：`login.html` 第 10 行

```html
<link href="https://cdn.jsdelivr.net/npm/remixicon@4.6.0/fonts/remixicon.css" rel="stylesheet" />
```

**问题**：CDN 不可用时图标全部失效，登录页品牌形象受损。建议将 remixicon 下载到本地。

### 🟡 问题

## 四、总结

### 问题统计

| 级别 | 数量 | 说明 |
|------|------|------|
| P0 | 4 | AI 助手网络/复制/输入/支付 + 语法错误 |
| P1 | 7 | lang 属性、CDN 依赖、侧边栏手势、暗色模式等 |
| P2 | 8 | 过渡动画、空状态统一、图片兜底等 |

### 建议优先修复顺序

1. **ai-assistant.html 网络检测 + 消息复制**（直接影响用户体验）
2. **my-evaluations.html 语法错误**（功能可能不可用）
3. **6 个页面 lang="en" → lang="zh-CN"**（修改简单，影响面广）
4. **ai-assistant.html 暗色模式 + 骨架屏**（提升视觉体验）
5. **add-order.html 支付方式完善**（商业功能关键）
6. **login.html CDN 本地化**（降低依赖风险）
