Quick Start

5 分钟本地跑起来

仅需 JDK 8、MySQL 8、Redis，前端免构建、无需 Node.js。

1

准备环境

JDK 8（必须）、MySQL 8.0、Redis 6+、Maven 3.6+。

2

建库建表

创建 utf8mb4 库，导入仓库内 schema*.sql 与最小种子数据。

3

启动访问

mvn spring-boot:run，浏览器打开三端地址即可。

bash
# 克隆并进入
git clone https://github.com/itxinfei/reggie.git && cd reggie

# 创建数据库（utf8mb4 防中文乱码）
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS reggie CHARACTER SET utf8mb4;"

# 建表（脚本可重复执行）
for f in src/test/resources/schema*.sql; do
  mysql -uroot -p --default-character-set=utf8mb4 reggie < "$f"
done

# 最小初始化数据（租户 / 门店 / 超管，必执行）
mysql -uroot -p --default-character-set=utf8mb4 reggie < db/seed-minimal.sql

# 启动
mvn spring-boot:run
访问地址
管理后台   http://localhost:8080/backend/index.html     admin / 123456
用户点餐   http://localhost:8080/front/index.html       手机号验证码登录
骑手端     http://localhost:8080/rider/login.html
接口文档   http://localhost:8080/swagger-ui.html

生产部署：mvn clean package -DskipTests 后以 prod profile 运行，敏感配置支持环境变量与 Jasypt 加密。

FAQ

常见问题

导入 SQL 中文乱码 / 建表报错？
最常见是漏了 --default-character-set=utf8mb4；建库时也要指定字符集。schema*.sql 可重复执行，报「表已存在」属正常。
建完表登录不了，提示用户名或密码错误？
建表脚本不含初始数据，必须再导入 db/seed-minimal.sql，否则 employee 表为空、无可登录账号。
AI 助手不工作 / 答得不对？
未配置供应商时走 Mock 占位模式（属预期）；已配置则检查启用状态、API Key 余额，并查看日志。短信/推送同样默认 mock-mode。
可以用于商业项目吗？
本项目基于 Apache-2.0 开源协议，允许个人与商业使用、二次开发与部署；建议保留原始版权声明。
接口报 429 / Redis 不可用？
限流基于 Redis 滑动窗口；Redis 故障时会降级为本地内存窗口（fail-closed，不直接放行），恢复后自愈。
想要带演示数据的完整建库脚本？
含 124 张表与各端演示数据的全量脚本未随仓库发布，可通过下方 QQ 群 / 私信作者获取。
