# 菜品管理页面样式审查报告

## 审查范围
- `src/main/resources/backend/page/food/list.html` (菜品列表)
- `src/main/resources/backend/page/food/add.html` (新增/编辑菜品)
- `src/main/resources/backend/styles/page.css` (页面样式)

---

## 一、整体布局与设计一致性

### ✅ 优点

| 方面 | 评价 |
|------|------|
| **布局结构** | 采用统一的 `dashboard-container` 容器，与分类管理页面保持一致 |
| **配色方案** | 主色调 `#409eff` (ElementUI蓝) 与系统风格一致 |
| **间距规范** | 使用 16px/20px/24px 的标准间距体系 |
| **圆角设计** | 统一使用 8px 圆角 |

### ⚠️ 发现的问题

#### 1. 内联样式过多

**位置**: list.html 多处

**问题示例**:
```html
<!-- 搜索框宽度硬编码 -->
<el-input style="width: 250px" ... />

<!-- 图片样式内联 -->
<el-image style="width: auto; height: 40px; border:none;cursor: pointer;" ...>
```

**建议**: 提取到 page.css
```css
.search-input {
  width: 250px;
}
.table-image {
  width: auto;
  height: 40px;
  border: none;
  cursor: pointer;
}
```

#### 2. 表单宽度硬编码不一致

**位置**:
- list.html: `width: 293px`
- page.css: `.addBrand-container .el-form-item__content { width: 293px; }`

**问题**: 293px 数值不语义化，list.html 和 add.html 样式作用域不同

**建议**: 统一为 300px
```css
.form-item-content {
  width: 300px;
}
```

#### 3. 重复的样式定义

**问题**: list.html 和 add.html 的 `<style>` 标签中，`.flavorBox` 相关样式大量重复

**建议**: 统一提取到 page.css 或创建独立的 flavor.css

- 表格字体 13px
- 按钮文字 14px

### ⚠️ 建议优化

#### 1. 缺少字体层级规范

**建议**: 定义清晰的字体层级
```css
.font-title {
  font-size: 16px;
  font-weight: 600;
  color: #1f2329;
}
.font-body {
  font-size: 14px;
  color: #606168;
}
```

#### 2. 价格显示缺少强调

**位置**: list.html 第130行
```html
<span>￥{{ scope.row.price/100 }}</span>
```

**问题**: 价格没有特殊样式

**建议**:
```css
.price-tag {
  font-size: 15px;
  font-weight: 600;
  color: #f56c6c;
}
```

## 六、响应式设计

### ❌ 严重问题：缺少响应式支持

**问题**:
- `min-width: 1366px` 强制最小宽度
- dialog 固定宽度 700px
- 表单元素固定宽度 293px

**影响**:
- 1920px 屏幕：内容偏左，右侧空白过多
- 1280px 屏幕：出现横向滚动条

**建议**:
```css
/* 1. 移除强制最小宽度 */
body {
  min-width: 1200px;
}

/* 2. Dialog 使用百分比宽度 */
.el-dialog {
  width: 90% !important;
  max-width: 700px;
}

/* 3. 表单响应式 */
.el-form-item__content {
  width: calc(100% - 120px);
  max-width: 300px;
}
```

## 八、代码质量

### ❌ 严重问题

#### 1. 代码重复严重

**问题**: list.html 和 add.html 的口味配置代码重复 80%

**建议**: 提取为组件
```vue
<!-- components/DishFlavorEditor.vue -->
<template>
  <div class="flavor-editor">
    <!-- 口味配置UI -->
  </div>
</template>
```

#### 2. 魔法数字过多

**问题**: 250px, 700px, 777px, 293px 等硬编码

**建议**: 使用 CSS 变量
```css
:root {
  --search-input-width: 250px;
  --dialog-width: 700px;
}
```

#### 3. 选择器嵌套过深

**问题**: list.html 第13-66行，嵌套 7 层

**建议**: 减少嵌套或使用 BEM 命名

## 九、无障碍访问

### ❌ 缺少支持

| 问题 | 影响 | 建议 |
|------|------|------|
| 缺少 aria-label | 屏幕阅读器无法识别 | 添加 aria-label |
| 图片缺少 alt | 图片无法被理解 | 添加 :alt="row.name" |
| 颜色对比度不足 | 色弱用户难以辨认 | 检查对比度 ≥ 4.5:1 |
